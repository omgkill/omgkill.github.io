Gollum Wiki Docker部署指南

by 啊沉
2024-04-02
约 232 字 - 预计阅读 1 分钟
技术文档 容器化部署

  1. 忽略 使用docker部署gollum, dockerFile

     1FROM ruby:2.4.1-alpine
 2MAINTAINER ilanni <ilanni@ilanni.com>
 3RUN set -xe \
 4&& echo "https://mirrors.aliyun.com/alpine/v3.4/main" > /etc/apk/repositories \
 5&& echo "https://mirrors.aliyun.com/alpine/v3.4/community" >> /etc/apk/repositories \
 6&& apk --update add alpine-sdk icu-dev git rsync openssh \
 7&& gem install gollum github-markdown \
 8&& rm -rf /var/cache/apk/* \
 9&& mkdir -p /gollum/ \
10&& git init /gollum/
11# Expose default gollum port 4567
12EXPOSE 4567
13
14ENTRYPOINT ["/usr/local/bundle/bin/gollum", "/gollum/"]
    • 另一个dockerfile
     1   FROM ruby:2.4.1-alpine
 2   RUN apt-get -y update && apt-get -y install libicu-dev
 3   RUN gem install gollum
 4   RUN gem install github-markdown org-ruby
 5   # RUN gem install --pre gollum-rugged_adapter
 6   RUN apt-get -y install cmake
 7   RUN gem install gollum-rugged_adapter
 8   VOLUME /wiki
 9   WORKDIR /wiki
10   CMD ["gollum", "--port", "80", "--adapter", "rugged", "--emoji", "--no-edit","--css","--js"]
11
12   EXPOSE 80

  2. 运行docker命令

    1 docker run --rm --privileged=true --name gollum -d -v D:/gg/wiki:/wiki -p 4567:4567 gollumwiki/gollum:master --css --js

  3. 启动后会报错 git repository 没有权限，或者不是当前用户等 ，进入docker里

    • cd /wiki
    • 设置这个 git config –global –add safe.directory /wiki
